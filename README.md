# JEPA研究地图

> 从潜在空间预测到可规划世界模型的可审计全景

[在线阅读](https://linwei-chen.github.io/jepa-research-atlas/) · [综合报告](docs/REPORT.md) · [浏览结构化数据](https://github.com/Linwei-Chen/jepa-research-atlas/blob/main/atlas.json)

JEPA把学习目标从像素或离散符号重建移到表示空间：编码上下文，预测目标表示，并通过非对称教师、显式正则或结构约束避免坍塌。领域已从图像遮挡预测扩展到视频动态、动作条件规划和多模态语义，但可预测性不等于因果性，表征质量也不自动保证长期闭环控制。地图用六条主路线和五级自主性阶梯区分这些进展。

## 路线导航

| 路线 | 主要关注点 |
|---|---|
| 理论与目标函数 | 定义JEPA原则、分析潜在预测的归纳偏置、坍塌条件及与重建范式的差异。 |
| 图像与静态表征 | 从图像上下文预测被遮挡区域或变换后视图的潜在表示，服务于通用视觉表征。 |
| 视频与时空动力学 | 利用时序遮挡、连续视图或长视频结构学习动作无关或弱动作条件的动态表示。 |
| 动作条件与控制 | 显式以动作或策略为条件预测未来潜在状态，并用于规划、强化学习或机器人控制。 |
| 多模态与跨域迁移 | 把联合嵌入预测迁移到音频、表格、图、点云、遥感、生理信号、语言或视觉语言。 |
| 评测、反证与边界 | 直接比较JEPA与重建、生成或其他潜在模型，或揭示鲁棒性、几何、长期规划和评测缺口。 |

## 如何阅读

1. 打开[在线地图](https://linwei-chen.github.io/jepa-research-atlas/)，先从“路线 × 层级”总览判断领域结构。
2. 用关键词和出版状态缩小范围，再点击聚合节点比较同一分支中的工作。
3. 进入详情页，按“问题—机制—证据—局限—启示—来源”下钻到单项工作。
4. 需要完整论证时，继续阅读[综合报告](docs/REPORT.md)与[检索与证据审计](docs/SEARCH_AUDIT.md)；需要二次分析时使用 `data/` 导出。

页面不依赖服务端。克隆仓库后可直接双击 `index.html` 离线阅读；论文原文、代码和数据集等外部链接需要联网。

## 研究范围与证据边界

覆盖截至2026-08-12可从一手入口核验的JEPA理论、图像、视频、动作条件世界模型、跨域迁移与评测反证；正式发表优先，关键预印本单列。不声称穷尽所有未使用JEPA名称的潜在预测方法。

地图把出版状态、阅读优先级、证据质量和展示层级分别记录，避免把“已发表”“重要”“证据强”或“工程成熟”混为一谈。详情页中的机制图是依据文字证据绘制的解释性示意，不替代原论文图表或独立复核。

## 项目文件

- `index.html`：交互式研究全景、路线说明、时间线与完整索引。
- `paper.html?id=...`：每项工作的机制、证据、局限和一手来源详情。
- `atlas.json`：人工维护的结构化研究真源。
- `docs/REPORT.md`：领域综述、关键分歧、时间线与开放问题。
- `docs/SEARCH_AUDIT.md`：检索范围、纳排规则、覆盖限制和反证记录。
- `data/papers.json`、`data/papers.csv`、`data/references.bib`：便于阅读、分析与引用的导出。
- `planning/` 中公开的账本文件：范围合同、查询、筛选和核心主张的可追溯记录。

## 数据更新与复核

网页和数据导出由 [`build-research-atlas`](https://github.com/Linwei-Chen/build-research-atlas) 从 `atlas.json` 确定性生成。更新记录后，应重新编译并执行严格验证与真实浏览器回归；不要直接改写 `data/` 中的派生文件。

这是一份有明确截止日期和纳入边界的研究综述，不声称覆盖互联网上的全部长尾资料。若发现题名、状态、链接或证据表述需要修正，欢迎在仓库中提交问题并附一手来源。
